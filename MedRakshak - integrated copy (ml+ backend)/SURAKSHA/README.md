# SURAKSHA

AI-powered pharmaceutical cold-chain monitoring and predictive intervention system.

## Core Features

- Real-time temperature, humidity and shock monitoring
- GPS-based shipment tracking
- Weather integration
- Pharmaceutical spoilage-risk prediction
- Remaining safe-time prediction
- Automated cooling alerts
- Cold-storage recommendation
- Route and rerouting recommendation
- Real-time monitoring dashboard

## Project Structure

- data/ - local datasets
- models/ - trained ML models
- outputs/ - generated outputs
- predict.py - ML prediction pipeline
- sensor_processor.py - sensor feature processing
- train.py - model training
- sanity_check.py - dataset validation
